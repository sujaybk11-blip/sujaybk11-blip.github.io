# Sujay BK portfolio
Open index.html in a browser or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000. Deploy the contents to GitHub Pages (root of a repository, Settings > Pages > Deploy from branch). No build dependency required. Edit project, education and skill data in site.js; edit identity/contact in index.html; colors in style.css. The particle effect is original Canvas code, not the Swarmline library. Project illustrations are conceptual SVGs, not actual screenshots. The original résumé includes a phone number; remove it from the PDF before publishing if you do not want it public. No contact backend; the form opens an email draft. Fonts use Google Fonts with local fallbacks. No custom domain configured.
